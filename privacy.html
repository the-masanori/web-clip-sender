PageText Sender プライバシーポリシー

最終更新日: 2026年9月23日

PageText Senderは、利用者が右クリックメニューで明示的に選んだときに、ページのURLと本文、または選択したテキストだけを新しいChatGPTタブへ入力し、送信を試みます。選択テキストの送信では、ページURLや本文を追加しません。

データの扱い

送信する内容は拡張機能がChrome内で処理し、利用者の操作に応じてchatgpt.comに送られます。開発者のサーバーには送信しません。広告、追跡、データ販売は行いません。送信先のChatGPTにおけるデータの取り扱いには、OpenAIのプライバシーポリシーが適用されます。

全文送信時に使う先頭プロンプトと元タブを閉じる設定は、Chromeの拡張機能ローカルストレージに保存します。送信待ちの本文または選択テキストはChromeのセッションストレージに一時保存し、送信試行後または対象タブが閉じられたときに削除します。診断ログや利用統計を開発者に送信しません。

権限

現在のページを利用者の操作時に読むためのactiveTab、右クリックメニューのcontextMenus、ページ本文の取得とChatGPTへの入力のためのscripting、設定と一時データの保存のためのstorage、chatgpt.comへの入力のための同サイトのホスト権限を使用します。

問い合わせ

質問や削除に関する問い合わせはサポートページで受け付けます。拡張機能を削除するとChromeに保存された拡張機能のデータは削除されます。ChatGPTに送信済みの内容についてはChatGPT側で管理してください。

Privacy Policy (English)

Last updated: September 23, 2026.

PageText Sender processes the current page URL and readable text, or only the selected text, when the user explicitly chooses the corresponding context menu action. It opens a ChatGPT tab, inserts the content, and attempts to send it. The selection action does not add the page URL or page body.

Content is processed within Chrome and sent to chatgpt.com at the user's request. It is not sent to the developer. The extension has no advertising, tracking, data sales, or developer analytics. OpenAI's privacy policy applies to data sent to ChatGPT.

The custom prompt and source-tab setting are saved in Chrome extension local storage. A pending message is temporarily saved in Chrome extension session storage and removed after the send attempt or when its target tab closes. The extension uses activeTab, contextMenus, scripting, storage, and chatgpt.com host access only to provide this user-initiated feature.

For support or deletion questions, use the support page. Uninstalling the extension removes its Chrome extension storage. Manage content already sent to ChatGPT through ChatGPT.
